# SDX_QoL
SDx - Quality of Life improvements to overall usage for engineers


Features:
1. On all SDx List sites you can now click a checkmark, hold-down SHIFT on your keyboard and click another checkmark. All checkmarks in between will be selected
2. ESC key clears all selected rows.
3. A new options button appears top right of all list pages. Allows clearing columns user may want to hide. 

<img width="514" height="749" alt="image" src="https://github.com/user-attachments/assets/8473e6a2-35d4-4dfc-a4db-fda456d09616" />

4. Rows Options: Allow user to adjust how many rows are displayed on each list page. Script keeps history per list page.

<img width="581" height="567" alt="image" src="https://github.com/user-attachments/assets/510763cb-b2ee-47a5-b7f7-dae8179fbb3e" />

5. To-Do list - Adds coloring for contract engineers/consolidators. 

<img width="478" height="708" alt="image" src="https://github.com/user-attachments/assets/e3da3a33-8df6-4fd0-bccf-eb833d25087f" />

6. Added a quick view option to list pages for any pdf. This is accessed by clicking the "eye" icon adjacent to the hyperlink.
   Note this viewer is rudimentary but allows quickly scrolling thru all documents in the list. Settings for the viewer are shown on the same button as columns/rows.
